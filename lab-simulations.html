DO · Lab Simulations

Do the job before you have the job.

Role-based security tasks drawn from real daily work — triage, review, investigation and remediation — assessed on the same published rubric as the Attack Reasoning Lab. Built for freshers and final-year students.

Concept preview. This page walks through one simulation task as the product is designed to run it. Lab Simulations are rolling out track by track; sign in to see which role tracks have simulations available today.
1

Pick a role and get a task list

Each role track has a set of tasks mirroring the first weeks in that job. A Cloud Security fresher starts with alert triage, an access review and a patch-priority call — not a capture-the-flag.

2

Read the brief, inspect the evidence

Every task ships with the artefacts you'd really be handed: a policy document, a log excerpt, a ticket, an architecture snippet. No hints hidden in the UI; you read it the way you would at work.

3

Do the work and submit

Flag what's wrong, write the fix, decide the priority — in your own words and your own structure. Copy-paste is disabled, as in every ThreatReady assessment.

4

Get task feedback and a score

What you caught, what you missed, and why it matters, scored on the published rubric with a model response beside yours. Progress is tracked per role and level.

Task brief

The Lambda role below was found during an access review. Flag every over-privilege and write the least-privilege replacement.

"Action": ["s3:*", "secrets:*"],
"Resource": "*"
Illustrative feedback
Flagged wildcard on s3:* and scoped it to one bucket
Removed secrets:* and named the one secret needed
Missed: Resource "*" still allows every bucket

Same rubric, same engine

Tasks are scored by the 3-Pass engine against the published rubric, so a simulation score reads the same way as a Lab score.

Built for day one, not year three

Beginner tasks are guided; the brief tells you what good looks like. Levels run Beginner → Intermediate → Advanced → Expert, like every ThreatReady track.

For cohorts too

Colleges and bootcamps can run simulations for final-year groups. Talk to us about cohort size and tracks.
